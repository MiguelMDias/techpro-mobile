# 💻 TechPro

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

Landing page para a TechPro, plataforma fictícia voltada a desempenho, segurança e usabilidade, oferecendo soluções tecnológicas para otimizar processos, proteger dados e impulsionar resultados.

## 🎯 Objetivo

Praticar a criação de uma página institucional/comercial responsiva, com foco em apresentação clara de proposta de valor e organização de seções (hero, benefícios, contato).

## ✨ Funcionalidades

- Layout responsivo (mobile e desktop)
- Seção hero com chamada para ação
- Cards de recursos/benefícios com efeitos visuais (glassmorphism, glow)
- Tema escuro com identidade visual própria

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (variáveis CSS, Flexbox, media queries)
